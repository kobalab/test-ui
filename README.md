# test-ui
電脳麻将のUIをテストする

リファクタリングやUI部品のテスト・調整のためのリポジトリです。

## デモ

https://kobalab.net/test-ui/demo/

## npm-scripts
| コマンド        | 説明
|:----------------|:-------------------------------------------
| ``release``     | リリース用にビルドする。
| ``build``       | デバッグ用にビルドする。
| ``build:js``    | JavaScriptのみデバッグ用にビルドする。
| ``build:css``   | CSSのみビルドする。
| ``build:html``  | HTMLのみビルドする。
